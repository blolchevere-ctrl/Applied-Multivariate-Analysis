# Applied Multivariate Analysis

Statistical and computational evaluations applying multivariate techniques for dimensionality reduction, feature extraction, and hypothesis testing.

## Overview
- **Multivariate Inference:** MANOVA / MANCOVA models.
- **Dimensionality Reduction:** Principal Component Analysis (PCA) and Factor Analysis.
- **Classification:** Linear & Quadratic Discriminant Analysis, Logistic Regression.

## Tech Stack
- **R / Quarto** for statistical modeling and HTML report generation.
- **Python (Scikit-Learn, Statsmodels)** for algorithmic implementation.
