## 🛠️ Step-by-Step Project Roadmap

- [ ] **Step 1: Data Preprocessing & Assumption Verification**
  - Data cleaning, missing value imputation, and outlier detection.
  - Verification of multivariate normality (Mardia Test) and covariance homogeneity (Box's M Test).
- [ ] **Step 2: Dimensionality Reduction & Feature Extraction**
  - Principal Component Analysis (PCA) with Scree Plot evaluations.
  - Exploratory & Confirmatory Factor Analysis with orthogonal rotation (Varimax).
- [ ] **Step 3: Group Differentiation & Classification**
  - MANOVA / MANCOVA model implementation and Pillai/Wilks lambda evaluation.
  - Linear Discriminant Analysis (LDA) and Quadratic Discriminant Analysis (QDA).
- [ ] **Step 4: Interactive Quarto Reporting**
  - Compiling analysis pipelines into executable Quarto HTML and PDF dashboards.
